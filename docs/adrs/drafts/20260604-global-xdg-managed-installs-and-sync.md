# ADR: Moved: Global / XDG Managed Installs and Sync

before the user-scope decision was rewritten. It is not a second active design.

That record is the sole current user-scope proposal and owns all further edits.

behavioral documentation belongs to later implementation issues. New references
must use the canonical draft path.
