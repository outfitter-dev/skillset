# Source Reference

Use this section when you need to locate or interpret authored Skillset source.

- [Workspace layout](workspace-layout.md) identifies the root manifest, source families, [provider-native](../../glossary.md#provider-native) islands, and operational paths.
- [Instructions](instructions.md) explains portable instruction source and its provider-specific [destinations](../../glossary.md#destination).
- [Preprocessing](preprocessing.md) defines variables, path references, partials, prompt arguments, and literal escaping in Markdown source.

For field-by-field shapes, use the generated [schema reference](../schemas/README.md). For current provider support, use the generated [support matrix](../support-matrix.md).
