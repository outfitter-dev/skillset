# Security Policy

## Supported versions

Skillset is pre-1.0 and evolves quickly. Security fixes are provided for the latest published npm release. Older releases are not supported; upgrade to the latest release before requesting a backport.

## Report a vulnerability

Do not open a public issue, discussion, or pull request for a suspected vulnerability. [Report the vulnerability privately through GitHub](https://github.com/outfitter-dev/skillset/security/advisories/new) so the maintainers can investigate before public disclosure.

Include enough information to reproduce and assess the report:

- the affected Skillset version and environment;
- a concise description of the vulnerability and its impact;
- reproduction steps or a minimal proof of concept;
- any known workarounds or mitigations; and
- relevant logs or screenshots with secrets and personal data removed.

Please keep the report and related details private until the maintainers confirm that disclosure is safe. The maintainers will use the private advisory to coordinate investigation, remediation, and disclosure with the reporter.
